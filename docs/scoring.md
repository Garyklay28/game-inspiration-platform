# 점수 기준

기획안 10장 「소재 점수」와 같은 내용이다. 계산 코드는 `yt_pipeline/score.py`에 있다.

```
Score_yt = w1·수요 + w2·아웃라이어 + w3·신선도 − w4·경쟁도
```

네 항목은 모두 0~1로 맞춘 값이다. 가중치는 처음에 모두 1.0이고 `config/pipeline.json`의 `score.weights`에 있다. 점수 범위는 −1~3이다. 같은 플랫폼 안에서 소재 순위를 정할 때만 쓰고, 조회수 예측치로 보여 주지 않는다.

## 1. 항목별 계산

| 항목 | 보는 것 | 계산 | 데이터 |
|---|---|---|---|
| 수요 | 지금 이 게임을 찾는 사람이 많은가 | 주제별 시간당 조회수 합을 후보 중 최댓값으로 나눈 값과, 인기 차트·검색 순위 가중치를 같은 방식으로 나눈 값의 평균. 순위 가중치는 1위가 1.0, 50위가 0.02 | 인기 차트(게임 카테고리, KR), 키워드 검색 |
| 아웃라이어 | 구독자가 적은 채널에서도 조회수가 나왔는가 | 영상 조회수 ÷ 채널 평균 조회수의 중앙값을 5로 나눔. 5배 이상이면 1 | `channels.list`의 총 조회수 ÷ 영상 수 |
| 신선도 | 아직 식지 않았는가 | 0.5^(게시 후 경과 시간 ÷ 72시간)의 중앙값 | 영상 게시 시각 |
| 경쟁도 | 같은 게임 영상이 이미 많은가 | 수집한 영상 중 같은 게임 영상 수를 후보 중 최댓값으로 나눔. 점수에서 뺀다 | 수집 풀 |

## 2. 계산 예시

숫자는 설명용이다. 수요 0.80, 아웃라이어 0.60, 신선도 0.50, 경쟁도 0.40이면 점수는 1.0×0.80 + 1.0×0.60 + 1.0×0.50 − 1.0×0.40 = 1.50이다.

## 3. 가중치 보정

1. 업로드한 영상을 `perf register`로 기획안과 연결한다.
2. `perf fetch` 또는 `perf manual`로 24시간, 72시간, 7일 조회수를 기록한다.
3. 샘플 데이터가 아닌 기획안의 영상이 8개 이상 쌓이면 `perf calibrate`가 항목별 점수와 log10(72시간 조회수)의 상관계수를 구한다.
4. 상관이 양수인 항목은 가중치를 올리고 음수인 항목은 내린다. 경쟁도는 빼는 항목이라 반대로 계산한다. 가중치는 0.2~2.0 사이로 자른다.
5. 결과는 `config/weights.proposed.json`에 제안안으로만 저장된다. 팀이 확인한 뒤 `perf apply`로 반영한다.

상관은 인과가 아니다. 표본이 적을 때는 결과가 크게 흔들린다.

## 4. 한계

1. 채널 평균 조회수는 채널 전체 누적값이라 최근 성과와 다를 수 있다.
2. 게임 매칭은 별칭 사전의 문자열 포함 여부로 한다. "doors"처럼 짧은 별칭은 다른 영상이 섞일 수 있다.
