# 에이전트별 Proof of Concept 결과 (빌리빌리 파트, 1차 결과물)

`python demo_agents.py --all --markdown docs/agent_outputs.md` 로 생성. 코드 도구 결과는 실제 Aside 수집 데이터로 다시 계산했고, LLM 결과는 실제 실행 기록 2026-11-25 (claude-sonnet-5-5) 입니다. 6 성과 기록만 가상의 예시 데이터입니다.

## 1 수집 · collector  (LLM, DB: raw_snapshots)


**입력**

- Aside 수집 파일 `data/aside/bilibili_2026-11-25.json` (수집 후 0.3시간)
- 기준: 파일 48시간 이내 · 영상 게시 30일 이내 · 신선한 영상 30개 미만이면 공개 API 보충

**코드가 한 일 (도구 결과)**


| 출처 | 영상 | 게시일 범위 | 30일 초과 |
|---|---|---|---|
| aside:综合热门 | 30 | 2026-11-23 ~ 2026-11-25 | 0 |
| aside:全站排行榜 | 20 | 2026-11-20 ~ 2026-11-25 | 0 |

- 핫키워드 31개 (Aside 10개 + 공개 API 핫서치 보충)
- 공식 활동·화제 8개: 王者荣耀UP主激励计划, 蛋仔奇思妙想计划, 崩坏：因缘精灵创作者激励计划, 英雄联盟赛事
- 데이터 출처 기록: Aside 영상(aside), Aside 핫키워드(aside), Aside 공식 활동·화제(aside), 공개 API · 실시간 핫서치(live)

**LLM 결과 — 실제 실행 기록 2026-11-25 (claude-sonnet-5-5)**

> Aside 파일(bilibili_2026-11-25.json, 0시간 경과)을 1순위로 사용해 게임 영상 50개(综合热门 30개, 全站排行榜 20개)와 공식 활동 8개를 수집했습니다. 핫키워드는 Aside 10개에 공개 API 실시간 핫서치 30개를 보충했습니다. 랭킹 스냅샷 파일은 없어서 추가하지 못했습니다.
- collector: Aside 핫키워드가 10개뿐이라 공개 API 핫서치 30개로 보충했는데, 이 핫서치에는 우주·NBA·AI 같은 게임 외 주제가 많이 섞여 있습니다.
- collector: 영상 50개는 모두 최근 게시물(综合热门 2026-11-23~11-25, 全站排行榜 2026-11-20~11-25)이라 오래된 영상은 없습니다.
- collector: 게임 카테고리 랭킹 스냅샷(ranking_game_*.json)이 없어 추가하지 못했습니다.
