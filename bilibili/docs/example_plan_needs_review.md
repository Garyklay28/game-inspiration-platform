## 开场钩子（3 种）
- **先看结果**：先说结论：同样是献给BLG的夺冠歌，《仰望星空》和《十年人间》唱的根本不是同一种情绪。接下来五分钟，我带你把它们拆开听。
- **提问** ✅ 采用：BLG夺冠之后，一下子出了好几首纪念歌，它们到底各自想表达什么？同样是庆祝，为什么听起来完全不一样？
- **挑战/反转**：都说夺冠歌就是“燃”，但我把几首歌放在一起听，发现它们的切入点并不一样，有的甚至不是在喊口号。

## 校验结果
- 规则检查：通过
- 审核意见：需修改
  - titles / script_sections(问题、正文) / thumbnail_brief：《春庭雪》被写成“同样献给BLG/为S16夺冠而作”的夺冠歌，但collector、engagement_analyst、localizer的数据里都没有这首歌，也没有任何来源说明它是BLG夺冠纪念曲。这是未经核实的事实陈述，三个标题和封面“三首夺冠歌”都以此为前提。
  - hooks[0] (先看结果) / hooks[2]：钩子写“唱的根本不是同一种情绪”“有的甚至不是在喊口号”，等于先下了结论。但脚本自己承认《十年人间》歌词原文尚未核实、只做主题概述，没有依据支持“情绪完全不同”这类绝对判断。被选用的是提问钩子，其余备选钩子也应避免未核实的断言。
  - rationale_zh：“一般的锐评和高光类视频反应低于音乐类”和“总播放5,353,569”在rationale里没有给出对应数字或出处（任务说明只提供了8.6~8.7%/1.45~1.46倍、《BLG夺冠吧》15.5%/2.60倍等，rationale也没有写15.5%）。论断与数字不对应，审阅者无法核对。
